## 一、P1 明显 Bug / 流程断裂（8 条，建议优先修）

### 1.1 听书播放器点击"播放"打崩 Blazor circuit（整页失活）`/browse`
- 现象：任意知识库卡片"🎧 听"→ 弹窗 → 点"播放"，console 报 circuit 终止、整页交互失效，且无任何错误提示。headless 与有头模式（真实 Edge 窗口）均复现——本机无系统语音包（speechSynthesis voices=0），**正常使用即可触发**。
- 根因：`wwwroot/js/speech.js` 的 `speakText` 无语音可用性检测与异常兜底，异常打崩 Blazor circuit。
- 期望：① 无可用语音时提示"当前环境不支持语音合成"并禁用播放；② JS 层 try/catch，播放失败只提示不崩页面。

### 1.2 搜索结果加载竞态：窗口期报"请先创建知识库"（与实际数据矛盾）`/search`
- 现象：打开页面后知识库筛选下拉需 3~4.5s 才渲染；期间搜索报"⚠️ 请先创建知识库"，但 /browse 明明有 7 个知识库——用户会误以为数据丢失。
- 根因：`Search.razor` 在 vaults 未加载完时 `firstVault==null` 直接置错误文案；页面无 loading 态。
- 期望：筛选区"加载中…"骨架 + 加载完成前禁用搜索；加载失败提示"知识库列表加载失败，请重试"。

### 1.3 错误提示指向死胡同：/settings 根本没有知识库路径配置 `/search`
- 现象："请先配置知识库路径后再搜索"的按钮跳 /settings，但该页只有模型/提供商配置，无任何知识库路径项。
- 期望：补配置项，或改指真正入口（/log-settings 或知识库管理），或删掉链接。

### 1.4 重复成员数据「小明 ×2」（同名同头像，LearnerId=1/2）`/family` 等全部家庭页
- 现象：家庭首页/家长看板/成就墙/互考/排行全部出现两个同名「小明」，甚至能"小明 vs 小明"互考（下拉里出现两次）。已直接调 API 证实是数据问题；创建成员无重名校验。
- 期望：清理重复数据（需工具）；`LearnerService.CreateAsync` 加重名校验；提供改名/合并入口。

### 1.5 「闻鸡起舞」成就按 UTC 判时：下午学习也解锁"早上 6 点前" `/dashboard` `/achievements`
- 现象：北京时间 13:29 学习 → 3 个成就同时解锁，其中"闻鸡起舞"（6 点前完成学习）不应解锁。
- 根因：`AchievementEngine.cs` 按 UTC 判断 `CreatedAt.Hour < 6`（库存 UTC）。
- 期望：按北京时间（+8）判断。

### 1.6 /log-errors 整页显示原始本地化键（页面基本不可用）`/log-errors`
- 现象：标题、4 个按钮、状态行、确认弹窗全是 `LogErrors_*` 键名（如 `LogErrors_ClearLocal`）。根因：`LogErrors_*` 键在 resx（1387 键）中缺失，IStringLocalizer 回退返回键名。
- 期望：补齐全部 `LogErrors_*` 中英文资源键；建议加"资源键缺失"自动化检查。

### 1.7 /qr-tool 二维码生成时序竞态（首次必失败）`/qr-tool`
- 现象：① 首次进入页面，服务器配对码/主 AI API Key 两个二维码空白（console：`Compact QRCode generation failed: TypeError: a.appendChild is not a function`）；② "通用二维码"首次点生成必失败，第二次才成功。点"刷新"即恢复——典型 Blazor ElementReference 竞态：容器未渲染完就调 JS。
- 期望：JS 调用前确保容器已渲染（StateHasChanged + 等渲染，或传 id 用 getElementById）；失败自动重试一次。

### 1.8 /local-models OpenVINO「已下载模型」删除无确认（一键删 7.8GB）`/local-models`
- 现象：OpenVINO tab 已下载模型列表的"删除"直接调删除 API，无任何确认；而同一页「概览」tab 的删除有自定义确认弹窗——同一危险操作两种待遇。
- 期望：补确认弹窗（模型名/大小/不可恢复警告，复用现有 `LocalModels_DeleteConfirm*` 文案）。

## 二、P2 易用性问题（17 条）

### 数据展示
- **2.1 阅读视图暴露原始 YAML frontmatter** `/note`、听书弹窗：正文顶部显示 `ai_generated/ai_provider/ai_model/generated_at(UTC)`，所有 AI 生成笔记中招；听书还会朗读出来。期望：阅读/听书模式剥离 frontmatter（编辑模式保留）；AI 来源用现有徽章样式展示（/browse 弹窗已这么做，行为应统一）。
- **2.2 打卡清单显示原始卡片 ID** `/checkin`："✅ 卡片 FE128CBB29200CEE 13:29"，家长看不出孩子学了啥。期望：显示卡片问题/标题。

### 交互与反馈
- **2.3 记账删除无确认** `/family-budget`：点"×"直接删、无撤销，财务数据误删风险高。期望：确认弹窗（含金额/分类/日期）。
- **2.4 家庭排行默认空数据** `/leaderboard`：默认"孩子榜"，本家庭成员全被硬编码归为"大人"，打开即"暂无数据"，需勾"显示全家排行"。期望：默认"全家"或按成员构成智能选榜；提供角色设置入口（TECH-08 遗留）。
- **2.5 场景切换半生效** `/messages` 等：顶部"📚知识库/👨👩👧家庭/🤖AI实验室"点击只换侧边栏菜单，URL 与主体内容不变。期望：真实跳转对应场景首页，或明确提示。
- **2.6 知识库浏览链路断裂** `/browse` `/cards`：① 卡片 hover 有 pointer/阴影暗示整卡可点，实际只有标题文字可点；② /cards 空状态引导"在浏览页点'生成 Anki 卡片'"，但该按钮全站不存在（真入口在 /generate）。期望：整卡可点；补"生成 Anki 卡片"入口（/browse 笔记弹窗、/note 详情页）或修正引导文案。
- **2.7 /master-stage 空值残缺页**：无参/无效 masterId 直达渲染"师父：（空白）"，空状态引导永不出现（`""` 与 `null` 判断错误）。期望：`IsNullOrEmpty` 时显示"请先选择一位师父"。
- **2.8 听书/笔记内容含 frontmatter**（同 2.1，合并处理）
- **2.9 /code-agent 本地提供方默认选中云端模型**：切"OpenVINO (本地)"后模型仍选中 `deepseek-v4-flash`（云端），无本地/云端标识，可能误走付费 API。期望：模型列表按提供方过滤、切换时重置为"提供方默认模型"、加本地/云端徽标。
- **2.10 /local-models 首屏"刷新中..."10~20 秒无进度提示**：后台并行扫描不可达的 Ollama/LM Studio/llama.cpp 拖慢整体，期间无任何解释。期望：分块加载（先出就绪内容）+ 具体文案（"正在检测 Ollama…"）+ 超时跳过不可达提供方。
- **2.11 /image-recognition "启动服务"链路不完整**：只有"启动"按钮，无"启动中..."态、无端口/日志信息、无"停止"入口，误点重操作后只能去别处关。期望：启动中态 + 服务地址/日志 + 停止按钮。
- **2.12 /ai-drawing 历史缩略图裂图**：`GET http://127.0.0.1:8788/api/comfy/file?...` 报 `ERR_BLOCKED_BY_ORB`（跨端口 5177→8788 响应被拦）。期望：文件端点返回合法类型/CORS 头或后端代理；至少给"图片加载失败"占位。
- **2.13 /openclaw 初始加载 12s+ 且"刷新"按钮一直禁用**：无加载提示，用户以为坏了。期望：spinner/文案，加载完再渲染按钮。

### 全站性问题
- **2.14 `<html lang="en">` 硬编码**（App.razor 第 4 行）：中文应用声明英文，影响读屏发音/翻译插件/无障碍。期望：`lang="zh-CN"`。
- **2.15 危险操作确认三套并存**：原生 confirm（Settings 删提供方、PromptTemplates 删模板、LogErrors 清日志、Tasks 删任务）、自定义 modal（LocalModels 概览、Tasks 清空历史）、无确认（LocalModels OpenVINO 删模型、记账删除、删除师父）。期望：统一自定义 modal（支持 Esc/点遮罩关闭）。
- **2.16 "删除师父"无确认** `/master-chat`：拜师有免责声明弹窗，删除却一键执行。期望：加确认。
- **2.17 自定义弹窗不支持 Esc/遮罩关闭** `/tasks`（清空历史弹窗实测 Esc 无效）。期望：统一支持。

## 四、功能建议（新增 / 删减 / 调整，13 条）

1. **搜索页加载态与容错**：知识库筛选区"加载中"骨架 + 失败重试；错误文案改"知识库列表加载失败"；删除/修正指向 /settings 的死链接。
2. **听书增强**：剥离 frontmatter；无语音环境提示；加进度条与"下一首"连播确认。
3. **Anki 入口闭环**：在 /browse 笔记弹窗与 /note 详情页补"生成 Anki 卡片"入口（对齐 /cards 空状态文案）。
4. **任务页**：默认折叠已完成任务或分页。
5. **场景切换**：改为真实跳转（或明确提示"即将前往 X 场景"）。
6. **首页卡片**：最近浏览/最近搜索加"清空"操作；"设备管理"卡片可点击。
7. **生成页默认模型**：默认改免费本地模型；"付费"标签加 tooltip。
8. **删除师父**：加确认弹窗。
9. **全站 lang=zh-CN** + 统一弹窗组件（原生 confirm → 自定义 modal，支持 Esc/遮罩）。
10. **成员管理**：重名校验 + 合并/改名工具（配合清理重复数据）。
11. **角色设置**：成员可设"孩子/大人"（修复默认孩子榜空数据根因）。
12. **本地模型页**：分块加载 + 具体检测文案 + 超时跳过；OpenVINO 删除补确认。
13. **资源键缺失检查**：加自动化测试防 /log-errors 类问题复发。
